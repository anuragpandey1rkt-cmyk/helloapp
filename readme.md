HelloApp 👋

A collection of simple Java programs and lab exercises created for practicing Java fundamentals, command-line arguments, strings, arrays, and basic programming concepts.

📌 About

HelloApp is a beginner-friendly Java practice repository containing multiple use cases and lab exercises. The programs demonstrate how to write, compile, and execute basic Java applications from the command line.

The repository includes simple greeting programs that progressively demonstrate:

Printing a basic Hello World message
Reading a name from command-line arguments
Handling multiple names
Working with strings and arrays
Practicing Java programming exercises

🚀 Getting Started
Prerequisites

Make sure you have the following installed:

Java Development Kit (JDK)
A terminal or command prompt
A code editor or IDE such as IntelliJ IDEA, Eclipse, or VS Code

You can verify your Java installation with:

java -version
javac -version
